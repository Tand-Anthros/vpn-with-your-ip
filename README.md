# vpn-with-your-ip (vpn-с-вашим-ip)
Take the provider's link and your server's VLESS key to obtain a VPN from the provider, configured for your IP address.  
(Воспользуйтесь ссылкой от провайдера и VLESS-ключом вашего сервера, чтобы получить VPN с вашим IP адрессом)  
<br>
Connect to the server via SSH, upload the `xray_deploy.py` script, and follow the instructions.  
(Подключитесь к серверу по ssh и загрузите туда скрипт `xray_deploy.py` и следуйте инструкции)
```
python xray_deploy.py
```

Afterwards, already on my PC.  
(После уже на своем пк)
```
python custom_sub.py
```

Follow the instructions and apply the modified configuration in happ or v2runTun.  
(Следуйте инструкции и подключите изменённую конфигурацию в happ или v2runTun)
